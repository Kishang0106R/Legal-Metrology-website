# Legal Metrology Compliance & Inspection Management System

Stage one is a UI foundation built with React, TypeScript, Vite, Tailwind CSS, and React Router.

## Run locally

```bash
npm install
npm run dev
```

The current stage includes public landing and services pages, login selection, a responsive department portal shell, dashboard visual placeholders, reusable UI components, and all major module routes. Authentication, persistence, OCR, compliance rules, laboratory processing, and reporting integrations are intentionally deferred.
